# Information Technology

Repositório técnico dedicado ao estudo, organização e documentação de conhecimentos relacionados à **Tecnologia da Informação**.

O conteúdo é estruturado de forma hierárquica, semelhante à organização de um livro técnico: parte dos principais domínios de TI e avança para seus respectivos conceitos, práticas, tecnologias, frameworks, ferramentas e aplicações.

---

## Objetivo

Construir uma base de conhecimento técnica, organizada e evolutiva sobre Tecnologia da Informação, reunindo:

- conceitos e fundamentos;
- estudos e referências;
- frameworks e normas;
- procedimentos técnicos;
- exemplos práticos;
- comandos e configurações;
- indicadores e métricas;
- diagramas e modelos;
- scripts e automações;
- estudos de caso;
- boas práticas.

O objetivo não é apenas registrar informações, mas relacionar os diferentes componentes da TI dentro de uma estrutura coerente.

Os diretórios poderão conter diferentes tipos de material.

Documentação destinada à compreensão teórica de determinado assunto.

Exemplo:

```text

```

Análises mais aprofundadas sobre determinado tema.

Exemplo:


### Procedimentos

Documentação prática para execução de atividades técnicas.

Exemplo:

```text

```

### Exemplos

Aplicações simplificadas destinadas à demonstração de conceitos.

Exemplo:

```text

```

Automações ou códigos utilizados como suporte aos estudos.

Exemplo:

```text

```

# Projetos

Este repositório concentra principalmente **conhecimento técnico, documentação, estudos e exemplos**.

Projetos completos, ferramentas ou aplicações desenvolvidas poderão possuir repositórios próprios.

Exemplo:

```text
Information-Technology
└── documentação, estudos e conhecimento

zabbix-itsm-integration
└── projeto de integração entre monitoramento e ITSM

netbox-inventory
└── projeto relacionado a inventário e NetBox

service-desk-dashboard
└── aplicação para acompanhamento de indicadores

infrastructure-automation
└── projeto de automação de infraestrutura
```

Dessa forma, o portfólio mantém uma separação entre:

```text
Conhecimento
    ↓
Aplicação
    ↓
Projeto
```

# Princípios de organização

O conteúdo deste repositório busca seguir alguns princípios.

### Hierarquia

Cada assunto deve estar localizado dentro do domínio ao qual pertence.

### Contexto

Tecnologias e ferramentas devem ser apresentadas dentro do contexto técnico em que são utilizadas.

### Relação entre assuntos

Sempre que possível, os conteúdos devem demonstrar as relações existentes entre diferentes áreas da Tecnologia da Informação.

### Aplicação prática

Conceitos teóricos podem ser acompanhados de exemplos, procedimentos, diagramas ou pequenos laboratórios.

### Evolução contínua

A estrutura pode evoluir conforme novos conhecimentos, tecnologias e áreas forem incorporados.
